# Finance Portfolio Management App

This is a full-stack **Stock Management System** designed for startups, utilizing a free API provided by **FinancialPrep** to obtain dummy data on various companies. The system allows registered users to log in and save preferred businesses and stocks to their personalized portfolio. Users can access comprehensive financial reports for each selected company, powered by data retrieved from the **FinancialPrep API**. These reports include key financial metrics and insights that support informed decision-making. The system's features are built to offer a straightforward user experience, making it easy to monitor favorite stocks, view detailed business profiles, and manage a tailored portfolio with essential financial information at hand.

<br />

## Technologies Used
- **Frontend**: 
  - **React.js**: For building the user interface and managing component-based architecture.
  - **Tailwind CSS**: For styling with a utility-first approach to create a responsive, modern, and user-friendly design.
  - **Typescript**: For better maintainability and type safety in the codebase.
  - **Axios**: For making API requests to the backend and retrieving financial data.
- **Backend**: 
  - **.NET Core**: The backend is built using .NET Core to handle API requests, authentication, and business logic.
  - **MsSQL**: A Microsoft SQL Server database is used to store user information and portfolio data.
  - **Entity Framework**: ORM to simplify database operations and migrations.
  - **JWT Authentication**: Secure authentication mechanism for logging in users.

   <br />

## Features
- **User Authentication**: Allows users to sign up, log in, and access their personalized portfolio.
- **Financial Reports**: Fetch and display detailed financial metrics, including stock prices, business performance, and more.
- **Portfolio Management**: Users can save, update, and view their portfolio with the selected stocks.
- **Search Companies**: Search for businesses and view their profiles, financial reports, and historical stock data.
- **Responsive Design**: The app is fully responsive, ensuring a seamless experience across devices.
